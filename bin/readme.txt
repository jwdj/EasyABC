Place the binaries (executables) for the programs abcm2ps, abc2midi, midi2abc,
abc2abc and nwc2xml here.  EasyABC will find them without the need
for any configuration by the user.

For Mac some dedicated folder are added in the repo to ease the build. They contained the binaries built with homebrew for each architecture. Move the ones corresponding to your processor architecture to the bin folder if you want to build the app or run directly the python scripts.
