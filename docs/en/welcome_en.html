Welcome to EasyABC 1.4

Thank you for using EasyABC. EasyABC is an open source editor for ABC music notation, available for Windows, macOS and Linux.

Highlights

  • Dark mode support, with possibility to force a sepia mode for the score when dark mode
  • MP3 and AAC export
  • Improved MIDI playback and follow score
  • Enhanced note selection on musicscore (enable multiple selection with Ctrl+Selection)
  • Allow to customize all colors for both mode
  • Native Apple Silicon support and new deb installation package
  • Many fixes and compatibility updates

Getting Started

  • Create a new tune from the File menu.
  • Open existing ABC files.
  • Use the score view to select notes directly.
  • Explore ABC Assist with the light bulb button.
  • Export to PDF, SVG, MIDI, WAV, MP3 or AAC.
