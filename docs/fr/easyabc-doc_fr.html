Introduction

EasyABC est un éditeur de partitions au format ABC, développé à l'origine par Nils Liberg et maintenu depuis 2015 par Jan Wybren de Jong, Seymour Shlien et Frédéric Aupépin. Il combine un éditeur de texte avec coloration syntaxique, une portée musicale rendue en temps réel et des outils de conversion vers MIDI, MusicXML, SVG, PDF et HTML.

La fenêtre principale est divisée en trois ou quatre volets redimensionnables : la liste des morceaux, la portée musicale, l'éditeur de code ABC et le panneau ABC assist (activé par l'icône ampoule de la barre d'outils). Un clic sur un morceau de la liste affiche sa partition et son code ; le bouton de lecture joue le morceau sélectionné.

Pour démarrer, copiez-collez ce code dans l'éditeur ABC :

X: 1
T: Mon morceau
K: C
CDEF | G2

La partition s'affiche en haut et un élément « Mon morceau » apparaît dans la liste des morceaux. Avec plusieurs morceaux, un clic simple dans la liste l'affiche ; un double-clic le joue (ou utilisez le bouton de lecture de la barre d'outils).

Installation

EasyABC repose sur des programmes externes installés dans le dossier bin/ : abcm2ps (rendu SVG), abc2midi (génération MIDI), abc2abc (transposition), Ghostscript ou ps2pdf (export PDF), xml2abc / abc2xml (MusicXML) et midi2abc (import MIDI).

  • Windows : lancez le programme d'installation, puis vérifiez les chemins dans Fichier ▸ Paramètres.
  • macOS : sur les versions empaquetées, les exécutables se trouvent dans le dossier Helpers du bundle de l'application.
  • Linux : EasyABC cherche les exécutables dans /usr/local/bin et /usr/bin, puis dans bin/ à côté du programme. Deux solutions s'offrent à vous : un paquet .deb qui installe automatiquement toutes les dépendances (voir plus bas), ou l'exécution depuis le code source (voir Exécuter EasyABC depuis les sources), valable sur toutes les plateformes.
  • Ghostscript (export PDF) : téléchargeable depuis ghostscript.com pour Windows ; pour macOS, un paquet précompilé est disponible sur la page de Richard Koch.
Astuce : sur Windows, Ghostscript est détecté automatiquement dans le registre ; il suffit en général d'indiquer gswin64c.exe dans les paramètres.

Fonctionnalités

  • Bonne couverture du standard ABC grâce à abcm2ps et abc2midi.
  • Coloration syntaxique et mise à jour automatique de la partition pendant la saisie.
  • Zoom de la partition et de l'éditeur.
  • Import MusicXML, MIDI et Noteworthy Composer (traduction MIDI→ABC maison, produisant un code lisible avec des liaisons de croches raisonnables).
  • Export MIDI, SVG, PDF, HTML (morceau courant ou carnet complet).
  • Sélection des notes à la souris et insertion de symboles via les menus de la barre d'outils.
  • Lecture MIDI du morceau actif, avec tempo et position réglables, bouclage et introduction (« count-in ») optionnelle à la façon d'un métronome.
  • Enregistrement depuis un clavier MIDI (y compris sous macOS via le synthétiseur du système).
  • Prise en charge d'Unicode (utf-8) et d'autres encodages.
  • Transposition et division/doublement des durées (via abc2abc).
  • Fichier de format abcm2ps configurable dans les paramètres.
  • Champs d'en-tête de fichier appliqués à tous les morceaux du carnet.
  • Alignement automatique des barres de mesure entre les lignes.
  • Disponible en anglais, français, italien, danois, suédois, etc.
  • Génération d'incipits, tri des morceaux et renumérotation des champs X:.
  • Recherche musicale : recherche de séquences de notes indépendamment de la tonalité, des ornements, des liaisons ou du champ L:.
  • Retrait automatique des liaisons de prolongation (« remove ties ») pour un rendu MIDI plus simple.
  • Prise en charge du « sticky rhythm » de MC Music Editor (L: mcm_default).

Saisie du code ABC

Une barre de mesure ABC est représentée par le caractère |. Comme tout le monde ne connaît pas cette touche par cœur, EasyABC offre une alternative : appuyez sur la touche Tab pour insérer une barre.

Avec un fichier contenant plusieurs morceaux, la partition est mise à jour et défilée automatiquement lorsque vous déplacez le curseur texte dans l'éditeur. Si vous cliquez avec la souris, la note la plus proche est mise en évidence (en rouge). Pour des raisons de performance, cela ne se produit pas avec les flèches du clavier ; appuyez alors sur Ctrl+L (Locate) pour forcer la mise en évidence manuellement.

Assistance de saisie

Le sous-menu Paramètres ▸ Assistance de saisie ABC active des corrections automatiques :

  • Majuscules/minuscules automatiques — les notes « C » et « c » correspondent à des octaves différentes. Avec ce mode, EasyABC choisit automatiquement l'octave la plus proche de la note précédente. Pour inverser la casse choisie, appuyez sur Shift en tapant la note. Désactivé par défaut.
  • Mode do-ré-mi — saisie en solfège (do, ré, mi…), avec un do mobile : « do » correspond à un « D » si la tonalité est D. Une seule lettre suffit (« r » pour « ré »), le septième degré se tape « ti ». Se combine avec le mode précédent. Désactivé par défaut.
  • Ajouter les durées — à l'appui sur Espace, EasyABC complète les durées pour que le groupe de notes totalise une noire. Avec L:1/8 : AB devient A2B2, ABC devient A2BC. Désactivé par défaut.
  • Ajouter les barres — quand Espace est pressé et que la mesure est complète, une barre | est ajoutée automatiquement.
  • Ajouter le symbole droit correspondant — « ( » entraîne « ) » ; idem pour [], {} et "".

Raccourcis d'édition

Lorsque deux notes ou plus sont sélectionnées (dans l'éditeur ABC ou dans la portée) :

ToucheEffet
( ou sAjoute (ou retire) une liaison de phrase autour des notes sélectionnées
.Active/désactive le staccato
< / >Rythme pointé (broken rhythm) ; peut aussi annuler un rythme pointé existant

Le raccourci de rythme pointé agit par paires : « AB CD » + > devient « A>B C>D ». Ces fonctions ne fonctionnent pas encore très bien sur les accords.

Portée musicale

Sélectionner des notes

Cliquez sur une note ou un silence dans la partition pour sélectionner le texte ABC correspondant — un lien direct entre représentation graphique et texte. Tracez un rectangle avec la souris pour sélectionner une plage de notes (maintenez Ctrl/Cmd pour ajouter à la sélection existante). Un clic sur une zone blanche désélectionne tout et place le curseur texte sur la note la plus proche — pratique pour insérer des accords ou des annotations au bon endroit.

Insérer des symboles

Sélectionnez la note concernée dans la portée, puis choisissez le symbole dans l'un des menus déroulants de la barre d'outils (ornements, nuances, articulations, etc.).

Zoom et pages

Un curseur dans la barre d'outils règle la taille de la partition. Les morceaux trop longs pour une page sont découpés en plusieurs pages, sélectionnables via un menu déroulant ; EasyABC fait défiler la partition automatiquement en suivant le curseur ABC, mais ne change pas de page tout seul. Pour les très longs morceaux, vous pouvez désactiver la mise à jour automatique et appuyer sur F5 pour rafraîchir.

Lecture et MIDI

  • Lisez le morceau avec le bouton de lecture ou F6 (Shift+F6 sur Mac).
  • Pendant la lecture, deux curseurs supplémentaires apparaissent : tempo (avec Ctrl+clic pour réinitialiser) et position de lecture.
  • Double-cliquez sur le bouton de lecture pour boucler.
  • Maintenez Ctrl en cliquant sur Lecture pour jouer sans les reprises.
  • Pour jouer un extrait, tracez à la souris un rectangle sur une partie de la partition : le passage surligné sera joué. Le rectangle doit englober une partie d'une ligne ou plusieurs lignes entières : il ne peut pas commencer en plein milieu d'une ligne et finir sur une autre.
  • Une fois un passage sélectionné, vous pouvez en ajouter un autre en maintenant Ctrl et en traçant un nouveau rectangle : les passages s'additionnent, y compris des morceaux de lignes différents.
  • Dans un morceau à plusieurs voix, le passage sélectionné peut concerner une ou plusieurs voix.
  • Le menu des paramètres MIDI permet de définir instruments par voix, volume, panoramique, accords de guitare (%%MIDI gchord), instruments d'accompagnement et de basse, tempo par défaut, transposition et accordage (-TT).
  • Une introduction rythmique (« count-in ») optionnelle peut être ajoutée automatiquement avant le morceau.
  • Enregistrement MIDI : appuyez sur Rec, jouez sur votre clavier MIDI, puis Stop. Le résultat est quantifié (avec détection de triolets) et converti en ABC. Sur macOS, la sortie passe par le synthétiseur MIDI du système.
Les commandes %%MIDI déjà présentes dans votre code sont respectées : EasyABC n'ajoute pas de doublons.

Import / Export

Pour ajouter un fichier ABC, XML, NWC ou MIDI au carnet courant, glissez-déposez-le sur la fenêtre EasyABC, ou utilisez Fichier ▸ Importer et ajouter…. Le menu Fichier ▸ Exporter (tout ou sélection) permet d'exporter le morceau courant ou tout le carnet dans différents formats :

  • MIDI — le fichier créé par la lecture est copié du cache vers l'emplacement de votre choix (le cache contient des fichiers à noms aléatoires, difficiles à retrouver ; l'export est la bonne méthode pour les conserver).
  • PDF — via Ghostscript ou ps2pdf (voir Installation).
  • HTML — la partition est intégrée en SVG dans le fichier HTML, affichable par tous les navigateurs sans logiciel spécial ; des extensions de navigateur permettent même de l'imprimer. La variante HTML interactif intègre le code ABC et le lie à la bibliothèque JavaScript abc2svg de Jef Moine (créateur d'abcm2ps) : le morceau est rendu dans le navigateur et peut y être joué en suivant la partition — une connexion Internet est nécessaire.
  • MusicXML — via abc2xml (code de Willem Vree, inclus dans EasyABC), format d'échange standard pour la musique numérique, p. ex. pour MuseScore.
  • ABC — contrairement à Fichier ▸ Enregistrer qui enregistre tout le fichier ouvert, cette option n'exporte que le morceau sélectionné.
  • WAV — le morceau est converti en MIDI par abc2midi, puis le MIDI en fichier audio WAV.
  • Les fichiers .nwc bénéficient d'un post-traitement : les textes en police Boxmarks sont traduits en décorations ABC (trille, coups d'archet, etc.) ; dans les morceaux à deux voix avec reprises et alternatives, les symboles de mesure de la première voix sont copiés vers la deuxième pour garantir un MIDI correct.
  • Les fichiers ABC sont lus en latin-1 par défaut ; ajoutez une ligne %%abc-charset utf-8 pour utiliser l'Unicode.
  • Export PDF via Ghostscript (gs ou ps2pdf, détectés automatiquement).

Impression : Fichier ▸ Imprimer imprime le morceau courant. Sur Windows et macOS, la qualité peut être limitée (rendu bitmap) ; pour une impression haute qualité, exportez d'abord en PDF.

Outils

Aligner les barres

Édition ▸ Aligner les barres aligne tous les | du morceau courant ; sélectionnez d'abord des lignes pour n'aligner que celles-ci. Le fonctionnement : chaque ligne est découpée en mesures et séparateurs (l'alignement distingue tous les symboles de barre : |, ||, |:, :|, |1, |:, ::, etc.) ; les mesures incomplètes sont complétées par des pseudo-éléments, et les séparateurs sont centrés sur le dernier | qu'ils contiennent. La détection des anacrouses (mesures incomplètes ne dépassant pas 80 % d'une mesure pleine, calculées à partir des champs M: et L:, triolets et rythmes pointés inclus) permet d'aligner correctement des lignes dont certaines commencent sur un temps faible ; les mesures internes peuvent également être alignées entre elles. L'opération est annulable.

Transposer

Édition propose la transposition vers le haut/bas et le changement des durées de notes (avec mise à jour du champ L:), via abc2abc.

Incipits

Outils ▸ Générer le fichier d'incipits produit un carnet d'extraits de débuts de morceaux (nombre de mesures, de reprises, de titres et critères de tri configurables) ; Voir les incipits affiche directement le PDF avec le modèle par défaut.

Trier et renuméroter

Le menu Outils permet de trier les morceaux (clé multi-champs, ex. « T,M » : titre puis métrique) et de renuméroter les champs X:.

Recherche

Si votre chaîne de recherche commence par « : », EasyABC entre en mode recherche musicale : il cherche des intervalles entre notes, indépendamment de la tonalité. Le mécanisme est le suivant : chaque note du morceau est convertie en numéro (C,, à b'' sur 43 degrés), et la suite des intervalles entre notes consécutives est codée en caractères ; la recherche s'effectue alors sur cette suite d'intervalles. La tonalité, les altérations, les notes d'agrément ({…}), les ornements (!…! / +…+), les annotations, les commentaires, les champs (X:, T:…, y compris embarqués [I:…]) et les blocs %%begintext/%%beginps sont ignorés ; la recherche fonctionne donc même si les deux versions utilisent des L:, des rythmes pointés ou des liaisons différents. Par exemple :gecc eceg trouve d2>B2 G2G2 (BG)Bd : les intervalles entre notes successives sont identiques dans les deux cas. La recherche est effectuée morceau par morceau (séparés par X:) et ne fonctionne pas sur les accords.

Interface

  • Chaque volet (« Liste des morceaux », « Code ABC », « Portée musicale ») peut être déplacé en glissant sa barre de titre ; les boutons à droite du titre réduisent/restaurent le volet.
  • Affichage ▸ Restaurer la disposition rétablit la disposition par défaut.
  • Taille de police de l'éditeur : Ctrl++ / Ctrl+−, ou Affichage ▸ Changer la police.
  • La fenêtre Messages affiche la sortie des programmes externes (abcm2ps, abc2midi…), utile pour diagnostiquer les erreurs de syntaxe ABC.

Fonctionnement interne (menu Internals)

EasyABC sert d'interface graphique à des programmes en ligne de commande (abcm2ps, abc2midi…). Les erreurs et avertissements ne s'affichent plus dans des fenêtres surgissantes : une note courte dans la barre d'état indique si le programme s'est exécuté normalement, et le menu Internals permet d'aller plus loin.

Messages

Affiche les communications entre EasyABC et les programmes externes : la ligne de commande complète (ex. abcm2ps - -O temp-…-.svg -v -A) et la sortie du programme. Par exemple stdin:18:15: warning: Line underfull signale une ligne de musique pas totalement remplie — souvent bénin. La fenêtre se rafraîchit à chaque opération (lecture, changement de morceau…). Les fichiers temporaires SVG et MIDI produits dans le dossier cache portent des noms longs et aléatoires pour éviter toute collision, notamment quand plusieurs instances d'EasyABC tournent en parallèle.

Morceau traité en entrée

Montre les données réellement envoyées au programme externe, avec numérotation des lignes pour faire le lien avec les avertissements. Le morceau contient des lignes ajoutées par EasyABC : marges pour abcm2ps (%%leftmargin 0.5cm, etc.) ou commandes %%MIDI pour abc2midi (instrument, volume, pan, accords…). Vous pouvez copier le contenu avec Ctrl+A / Ctrl+C.

Fichier MIDI désassemblé

Affiche le fichier MIDI sous forme de texte (via midi2abc -mftext). Fonction avancée utile pour diagnostiquer un problème de lecture : chaque ligne liste le temps en temps, la commande, le canal MIDI (1–16), la hauteur et la vélocité. Les fichiers simples donnent un MIDI à une piste ; les fichiers avec voix ou accords de guitare donnent plusieurs pistes (une par voix, plus basse/accords).

État des paramètres

Affiche le contenu lisible du fichier settings1.4.dat où EasyABC stocke sa configuration. En cas de blocage, Paramètres ▸ Redémarrage à froid (Cold Restart) rétablit les réglages d'usine.

Les fichiers temporaires (SVG, MIDI) et settings1.4.dat se trouvent dans un dossier caché : AppData/Local/EasyABC sous Windows, un dossier précédé d'un point (ex. .EasyABC) sous Linux. Le menu Paramètres ▸ Vider le cache indique l'emplacement du cache. Si EasyABC ne démarre plus, supprimez settings1.4.dat ou utilisez le redémarrage à froid : un fichier de paramètres par défaut sera recréé.

Paramètres ABC

La boîte de dialogue Fichier ▸ Paramètres ABC est un carnet à onglets. Survolez les contrôles avec la souris : des info-bulles expliquent la plupart d'entre eux. Les réglages sont mémorisés dans settings1.4.dat.

Fichiers

  • Chemins vers les exécutables (abcm2ps, abc2midi, abc2abc, midi2abc, Ghostscript…). Vérifiés à chaque démarrage. Les chemins sont mémorisés dans des listes déroulantes pour basculer facilement entre plusieurs versions.
  • Windows : gswin32c.exe ou gswin64c.exe pour le PDF ; macOS : pstopdf ou Ghostscript ; Linux : gs.
  • Un lecteur MIDI externe peut être indiqué (ex. TiMidity sous Linux, avec ses paramètres dans « Paramètres supplémentaires du lecteur MIDI », par ex. -ik -A 50).
  • Le bouton Restaurer les paramètres remet à zéro les chemins vidés.

Abcm2ps

  • EasyABC par défaut : rendu familier garanti. Pas de réglages de page : EasyABC n'ajoute aucune commande si votre morceau contient déjà sa propre mise en page abcm2ps. Pour personnaliser, décochez les deux cases : marges, largeur/hauteur de page et échelle apparaissent (valeurs en cm, sans unité).
  • Numérotation des mesures, référence X: avec le titre, suppression des paroles, ignorance des fins de ligne (%%continueall).
  • Champ Paramètres supplémentaires : toute option en ligne de commande d'abcm2ps (ex. -i pour localiser les erreurs). Vérifiables via Internals ▸ Messages.
  • Un fichier de format (.fmt, ex. microtons turcs commaA-E.fmt) peut être indiqué ; abcm2ps ne trouve pas les %%format référencés dans le morceau sans chemin complet.

Abc2midi

  • Tempo par défaut (120 bpm si aucun Q:), instrument par défaut (piano acoustique), volume et pan de la mélodie.
  • Accords de guitare : activation, instrument/volume séparés pour la basse et pour les accords (deux canaux MIDI distincts), motif gchord personnalisable.
  • Transposition (ex. clarinette en Si♭) et accordage (±1 demi-ton, option -TT)
  • Options : ignorer les nuances (-NFNP), ignorer les notes d'agrément (-NGRA), ignorer les fermatas (-NFER), modèle d'accentuation Barfly (-BF).
  • Compte à rebours (Count in) : deux mesures de clics de métronome avant le morceau, adaptées à la signature rythmique.
  • Si le morceau contient déjà des commandes %%MIDI, EasyABC n'insère pas de doublons : modifiez alors le code ABC directement.

Voix

Pour les morceaux multivoix (V:). Les instruments sont définis par voix (16 canaux MIDI disponibles ; le canal 10 est réservé aux percussions). Sur Mac, des codes de contrôle sont ajoutés en préambule pour contourner les particularités de QuickTime. Les superpositions de voix (voice overlays, « & ») sont prises en charge mais restent peu intuitives. L'option « valeurs séparées par voix » permet de définir instrument, volume et pan pour chacun des 16 canaux.

XML

Options de conversion MusicXML ⇄ ABC (xml2abc / abc2xml), considérées comme expérimentales. MuseScore est une bonne solution complémentaire pour afficher et jouer des fichiers MusicXML.

ABC assist

ABC assist est utile aux débutants comme aux utilisateurs expérimentés. Activez-le en cliquant sur l'icône ampoule de la barre d'outils : le panneau apparaît en bas à gauche (il peut être amarré ou flottant, et suit le mode sombre). Il est contextuel : il analyse la position du curseur (en-tête de fichier, en-tête de morceau, corps du morceau, ligne vide…) et propose la description de l'élément ABC sous le curseur (champ, directive, note, barre…) avec les actions applicables — le tout en liens cliquables. La documentation affichée provient de la référence ABC standard et, pour les directives, de la documentation d'abcm2ps et d'abc2midi en ligne.

Démarrer un morceau

Sur un fichier vide, cliquez sur Nouveau morceau : ABC assist génère un squelette complet (en-tête %abc-2.1, X:, T:, C:, M:, L:, Q:, K:C avec le numéro X: suivant le dernier utilisé). Trois modèles sont disponibles :

  • Morceau simple — une voix en do majeur, 4/4 ;
  • Morceau multivoix — quatre voix SATB avec clés, mise en page %%score [ (S A) (T B) ] et instruments MIDI par voix ;
  • Partition de percussion — deux voix en clé perc, avec %%MIDI drummap (canal 10) et des motifs de batterie prêts à écouter.

Il est aussi possible d'ajouter une voix à un morceau existant (V: suivant, clé de sol), et de retirer des voix d'une directive %%score/%%staves.

Saisie des notes et accompagnement pendant l'édition

Sur une ligne vide du corps du morceau, le panneau propose d'insérer une note ou un silence (C…b, z) ; les barres | sont insérées automatiquement quand la mesure est pleine. Des boutons Nouvelle ligne et Espace existent pour ceux qui préfèrent la souris. Sur une note existante, le panneau offre :

  • Hauteur : note sup/inf, tierce sup/inf, octave sup/inf ; altération (bémol, bécarre, dièse, doubles et quarts de ton) ; « simplifier la note » pour réécrire l'octave sous forme canonique ;
  • Durée : par défaut, moitié, double, pointée, rythme pointé (>/<), liaison de prolongation (-) ; pour les silences : visibilité (z vs x), silence de mesure (Z/X) et nombre de mesures ;
  • Groupes : liaison de phrase (slur, pleine ou pointillée), triolet sur trois notes sélectionnées, ligature (beam) pour lier plusieurs croches sous une même barre, conversion en accord [[CEG]] ; notes d'agrément (appoggiatura/acciaccatura) ;
  • Décorations : nuances (pppp→ffff, sfz, crescendo/ diminuendo), ornements (trille, mordant, roll, turn, arpège), articulations (staccato, accent, marcato, tenuto, coups d'archet, pédale…), doigtés (0–5), repères de direction (segno, coda, D.C., D.S., fine) — avec images et symboles redéfinissables (U:) ;
  • Annotations et symboles d'accord : insertion, position (dessus/dessous/gauche/droite), conversion annotation ⇄ accord ; pour les accords, suggestion des accords relatifs à la tonalité du morceau et modification du nom (m, 7, M7, dim, sus, 9…) et de la basse (/G) ;
  • Barres et fins alternatives : barre simple, double, finale, point de reprise, première/seconde finition, barre invisible, superposition de voix (&).

En-tête et champs

Dans l'en-tête du morceau, le panneau permet de changer la signature (nombre de dièses/bémols ou none) et le mode (majeur, mineur, dorien, phrygien, lydien, mixolydien, locrien) sans transposer la tonique affichée, la clé (sol, fa, ut, perc… avec transposition d'ut et ±8va), la mesure (C, C|, 2/4…12/8), la longueur unitaire L:, le tempo (nom — Allegro, Presto… — et/ou métronome, longueur de note référencée), les transpositions d'octave et de lecture, et la visibilité des champs (%%writefields). La numérotation des mesures (%%measurenb/%%barnumbers) est aussi pilotable.

Directives MIDI

Sur une directive %%MIDI, le panneau propose :

  • Instrument (%%MIDI program) : la liste complète des 128 instruments General MIDI, canal éventuel inclus ;
  • Canal (1–16) ; volume (control 7, chordvol, bassvol) affiché en pourcentage avec une jauge visuelle ;
  • Percussions : %%MIDI drummap et %%percmap avec la liste complète des instruments de percussion General MIDI 2 (caisse claire, charley, toms, cymbales…) ;
  • Accords de guitare (%%MIDI gchord) : motifs prédéfinis adaptés à la mesure (binaires ou ternaires), éditeur de motif (f = fondamentale, c = accord, z = silence, 2 = durée double, G/H/I/J = notes de l'accord…) et réglage du temps.

Sur %%score/%%staves : montrer une seule voix, ajouter/retirer des voix affichées, grouper sur la même portée (parenthèses), accolades ou crochets, et activer/désactiver les barres de mesure continues entre portées.

Enfin, le panneau détecte les caractères invalides et propose de les remplacer, affiche la description de chaque directive abcm2ps avec un lien « apprendre davantage » vers la documentation en ligne, et masque les options rares derrière une flèche « plus d'options » pour limiter le défilement.

Sortie audio

EasyABC s'appuie sur des synthétiseurs MIDI pour produire le son. La prise en charge native du MIDI s'est raréfiée sur les systèmes récents (le lecteur Windows Media n'est même plus livré par défaut avec Windows 10), et la lecture se configure donc parfois manuellement :

  • Windows : la lecture fonctionne généralement sans effort ; le suivi de partition pendant la lecture fonctionne dans les deux sens.
  • macOS : sortie via le synthétiseur MIDI du système (QuickTime / mplay).
  • FluidSynth : si la bibliothèque fluidsynthplayer est disponible, EasyABC joue le morceau via un SoundFont (.sf2) indiqué dans les paramètres — des timbres bien plus réalistes que le synthétiseur GM par défaut. Attention : les lecteurs comme TiMidity et FluidSynth ne sont pas livrés avec SoundFont ; il faut installer un .sf2 et indiquer son chemin (ex. /usr/share/sounds/sf2/FluidR3_GM.sf2 sous Linux).
  • Linux : si la lecture ne produit aucun son, la solution simple est de définir fluidsynth comme lecteur MIDI ; la solution complète passe par JACK : démarrez jackd et ajoutez --audio-driver=jack --connect-jack-outputs dans les paramètres du lecteur MIDI.
  • En dernier recours, un lecteur MIDI externe peut être défini dans Fichier ▸ Paramètres ▸ Fichiers — mais le suivi de partition ne fonctionne alors plus.

Rechercher dans des fichiers

Cette fonction du menu Édition permet de chercher dans une grande collection de fichiers ABC des mots figurant dans les titres, compositeurs, paroles, etc. Par exemple, pour trouver tous les morceaux de Bach en ré et en 9/4 :

C:bach M:9/4 K:G

À la première utilisation, indiquez le dossier racine de vos fichiers ABC (sous-dossiers inclus) ; l'outil s'en souvient pour les recherches suivantes. Un clic sur un résultat charge le fichier dans EasyABC, positionné sur le morceau trouvé. La recherche exhaustive peut être longue : la barre de progression permet de l'interrompre.

Exécuter EasyABC depuis les sources

Cette procédure est commune à Windows, macOS, Linux et Raspberry Pi ; sous Linux et Raspberry Pi, c'est la façon recommandée de lancer EasyABC. Récupérez d'abord le code depuis la branche release-1.4.0 du dépôt GitHub (bouton Code ▸ Download ZIP, ou git clone -b release-1.4.0).

Avec un environnement virtuel Python (recommandé)

  1. Installez Python 3.10 ou supérieur (les versions testées en priorité sont la 3.12 et la 3.13) : pour Windows et macOS, téléchargez-le depuis python.org/downloads ; sous Linux, utilisez le paquet python3 de votre distribution.
  2. Créez un environnement virtuel et installez les dépendances listées dans requirements.txt :
python -m venv venv          # python.exe -m venv venv sous Windows
pip install --upgrade pip
pip install -r requirements.txt

L'environnement virtuel est illustré ici avec venv, mais d'autres solutions (uv, virtualenv, conda…) fonctionnent de la même façon. Le fichier requirements.txt couvre notamment wxPython 4.2.x (interface graphique), pyparsing et, pour l'empaquetage macOS, py2app. Sous Windows, installez aussi py -m pip install pywin32 pygame si nécessaire. Lancez ensuite python3 easy_abc.py (ou double-cliquez sur easy_abc.py sous Windows) ; en cas de plantage, démarrez-le depuis une fenêtre de commandes pour lire les messages d'erreur.

Avec les paquets de la distribution (Debian et dérivés)

Sur les distributions de type Debian (Debian, Ubuntu, Mint…), il est aussi possible d'installer les dépendances comme paquets système au lieu d'un environnement virtuel :

sudo apt install python3-wxgtk4.0 python3-pyparsing python3-six \
  python3-pygame fluidsynth abcm2ps abcmidi fluid-soundfont-gm

Puis lancez directement python3 easy_abc.py. Attention toutefois : les dépôts Debian/Ubuntu fournissent actuellement wxPython 4.2.0, qui déclenche une erreur « Bad perspective string » au démarrage dans certains cas ; ce bug est corrigé à partir de wxPython 4.2.3 (voir l'issue jwdj/EasyABC #126, qui détaille aussi l'installation sur openSUSE, Debian, Ubuntu et Mint). L'environnement virtuel, qui installe wxPython via pip, reste donc la solution la plus sûre.

Raspberry Pi : EasyABC fonctionne sur Raspberry Pi 4 (merci à John Lowry pour le compte rendu) : installez abcmidi abcm2ps fluid-soundfont-gm python3-wxgtk4.0 et, si besoin, compilez FluidSynth (cmake, make libfluidsynth) puis copiez libfluidsynth.so* à côté de easy_abc.py. Le SoundFont par défaut est /usr/share/sounds/sf2/FluidR3_GM.sf2. Note : l'impression ne fonctionne pas correctement ; exportez un PDF et imprimez-le avec un autre programme.

Historique des versions

Résumé des évolutions depuis la version 1.3.5 — le détail complet figure dans le journal des modifications du dépôt.

1.3.5.P6 – P9 (correctifs)

  • Compatibilité avec les versions récentes d'abcm2ps (suffixes in/px sur largeur/hauteur des SVG) — patch de Frédéric Aupépin.
  • Lignes trop pâles (portées, barres, hampes) corrigées sous Linux.
  • Instruments séparés pour accord, basse et chaque voix ; nouveaux réglages %%MIDI par voix.
  • Boucle de lecture fiabilisée (événements MEDIA_FINISHED/STOP).
  • F7 arrête le lecteur MIDI ; flèches du clavier synchronisées avec la note surlignée  mise à jour de la traduction italienne.

1.3.6 – 1.3.6.4 (2015)

  • Refonte majeure : menu Internals, paramètres en carnet à onglets.
  • Suppression du cache permanent : les fichiers temporaires (temp.abc, temp001.svg…) sont désormais écrasés à l'exécution.
  • Nouvelle recherche de morceaux dans un dossier et ses sous-dossiers.
  • Redémarrage à froid (Cold Restart).
  • Performances de rendu SVG nettement améliorées (J.W. de Jong), nommage unique des fichiers MIDI/SVG entre instances.
  • Volume par défaut porté de 64 à 96 ; compteur de mesures, option « count-in » à deux mesures.

1.3.7.x (2016–2019)

  • ABC Assist : fenêtre amarrable ou flottante, triplets, liaisons, accords, microtons, gabarits multivoix/percussions, choix d'instruments et volume MIDI.
  • Raccourcis de navigation entre pages : Ctrl+Alt+PgSuiv/PgPréc, Début/Fin.
  • Compatibilité Python 3 (2 et 3 simultanément à partir de 1.3.7.4).
  • « Follow score » (suivi de partition pendant la lecture) avec case à cocher et compensation de synchronisation.
  • Export multi-sélection (impression, ABC, PDF unique)  traductions néerlandaise et allemande.

1.3.8.x (2020–2021)

  • Recherche dans les fichiers (Ctrl+Shift+F) avec champs ABC (ex. C:mozart M:3/4) ; mode exclusif en ligne de commande (-exclusive).
  • Python 2 définitivement abandonné ; installateur Windows passé à Python 3.
  • Export WAV via FluidSynth ; export « HTML interactif » via abc2svg de Jef Moine.
  • Mode tablette : plein écran (Shift+Alt+F), navigation par zones cliquables de l'écran.
  • Son de démarrage instantané (SoundFont léger puis bascule au premier jeu) ; FluidSynth 2.x, driver pulseaudio par défaut.
  • Traduction chinoise  suppression puis rétablissement du menu « Insérer un symbole ».

1.4.0.0

  • Nouveaux exports : MP3 et AAC (via le réglage ffmpeg) ; couleurs distinctes pour sélection et suivi ; couleurs de l'éditeur personnalisables.
  • Nouveau : gestion du mode sombre (dont icônes de barre d'outils), menu « liste interne des morceaux ».
  • Lecture MIDI sur Mac via le synthétiseur DLS d'Apple (bibliothèque mplay).
  • Améliorations : surlignage des notes suivant le curseur, sélection graphique multivoix, respect de %%abc-charset, titre de fenêtre marquant les modifications non enregistrées.
  • Mises à jour de xml2abc/abc2xml et adaptation aux nouvelles versions d'abcMIDI et de Python  nombreux correctifs de lecture, d'affichage et de copier-coller.
